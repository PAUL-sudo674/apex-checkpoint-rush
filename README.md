# Apex Checkpoint Rush

Build a polished, playable browser car racing game prototype called Apex Street Racer. Use a modern dark racing-game visual style with a full-screen 3D-style driving environment. Implement an actual playable game loop (not just a landing page): a player car driving along a road/track with steering, acceleration, braking, speedometer, lap counter, countdown/start, checkpoints, collision boundaries, and a restart button. Use Three.js or React Three Fiber if supported; otherwise use a performant Canvas-based pseudo-3D racer. Support keyboard controls (W/Up accelerate, S/Down brake, A/D or Left/Right steer, Space handbrake) and touch controls for mobile. Add a start/menu screen, race HUD, pause/resume, and finish state with time/result. Include polished lighting, road markings, roadside scenery, sky/environment, camera follow, responsive layout, clear control hints, and sound toggle (sound can be simple synthesized effects; default muted). Make it genuinely playable and test/fix runtime errors. No login or database required. Use TypeScript, Tailwind and shadcn/ui where suitable. Project name: Apex Street Racer.
